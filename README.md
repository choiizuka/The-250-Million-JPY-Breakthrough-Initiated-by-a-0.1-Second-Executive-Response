## 5. 数理モデル / 確率モデル (Mathematical Model)

地球上の総人口（ $N = 80\text{億人}$ ）を母集団とし、以下の3つの独立した変数（レイヤー）が同時に成立する確率を掛け合わせるアンサンブルモデルを構築する。

$$P(\text{Total}) = P(A) \times P(B|A) \times P(C|A \cap B)$$
